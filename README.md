# 크샬로스 보스전 — 비공식 개인 포트폴리오

**▶ 바로 플레이 : https://choijiha.github.io/mongil-boss-portfolio/**

> 이 저장소는 게임 기획 포트폴리오용으로 만든 **비공식 개인 프로젝트**입니다.
> 『몬길: STAR DIVE』를 바탕으로 한 팬 창작물이며, 원작사·운영사와 관련이 없고 상업적 목적이 없습니다.
> 원작 게임에서 추출한 그림 파일은 사용하지 않았습니다.

## 게임 소개

쿼터뷰 2D 보스전입니다. 캐릭터 3명(오필리아 · 프란시스 · 지원)을 교체하며 **3분 동안** 창작 보스 **크샬로스**에게 최대한 많은 피해를 주는 것이 목표입니다.

- 보스 체력을 깎을 때마다 단계가 오르고, **5 · 15 · 20단계**에서 단계 기믹(습격 · 심연의 추격 · 무영)이 시작됩니다.
- 노란 고리가 뜨는 공격은 **회피 후 좌클릭(회피 반격)** 또는 **캐릭터 교체(교체 반격)** 로 무력화할 수 있습니다.
- 최종 점수 = 피해량 점수 + 미션(기믹 무력화) 점수. 전투가 끝나면 결과 화면에 별(최대 20개)이 표시됩니다.

## 조작법

| 키 | 동작 |
|---|---|
| W A S D | 이동 |
| 마우스 왼쪽 클릭 | 공격 (마우스가 가리키는 쪽) |
| Space | 회피 (이동 방향) |
| 1 · 2 · 3 | 캐릭터 교체 |
| E | 스킬 |
| Q | 궁극기 |
| R | 처음(파티 편성)으로 |
| H | 조작 설명판 열기/접기 |

- 시작 : 파티 편성 화면에서 **편성 → 캐릭터 3명 선택 → 편성 확정 → 전투 시작**, 보스에게 걸어가면 나오는 확인창에서 **도전(Space)**.
- 시험용 키(바로 보기) : 4 = 방출, U = 3연 할퀴기, 9 = 15단계, 0 = 20단계, 5 = 은신 기습 시험. T = 개발용 표시, Y = 개발용 표시를 켠 채 화면 글씨·테두리만 숨기기.

## 권장 환경

- **PC + 키보드·마우스**, 최신 Chrome 또는 Edge
- 1920×1080 화면에서 **전체 화면(F11)** 권장 (16:9로 꽉 차게 그려집니다)
- 소리 켜기 권장 — 브라우저 규칙 때문에 **화면을 한 번 클릭한 뒤부터** 소리가 납니다.

## 제작과 AI 활용

- **기획 (제작자)** : 창작 보스 '크샬로스' 기획서를 바탕으로 한 보스 패턴·단계 기믹 구현 방향, 캐릭터별 스킬·반격 연출 방향, 밸런스(체력·피해·범위·시간)와 연출·소리의 수정 지시, 플레이 확인.
- **코드** : AI 코딩 도구 **Claude Code**가 제작자의 지시에 따라 작성했습니다 (HTML5 Canvas + JavaScript, 외부 라이브러리 없음).
- **그림** : 제작자가 준비한 그림을 정리해 사용했습니다 (캐릭터 스프라이트 시트 등은 AI 이미지 생성 도구로 만든 것).
- **소리** : 제작자가 준비해 제공한 효과음·음성 파일을 사용했습니다 (일부 보스 소리는 제작자가 준비한 참고 음원에서 구간을 잘라 사용).

별도의 오픈소스 라이선스는 부여하지 않았습니다.

## 알려진 제한사항

- 그림·소리 파일이 많아(약 345MB) **처음 접속할 때 불러오는 데 시간이 걸릴 수 있습니다.** 다 불러오기 전에는 일부 그림이 도형으로 보일 수 있습니다.
- 모바일·터치 조작은 지원하지 않습니다.
- 기록 저장 기능은 없습니다 (새로고침하면 처음부터).
- 밸런스 수치는 시험 중인 값입니다.
